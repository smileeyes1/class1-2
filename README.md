# LMS Offline Class 1-2 System

نظام إدارة تعليمي فلسطيني يعمل بدون إنترنت (Offline LMS)

## المميزات
- منهاج رياضيات الصف الأول والثاني
- توليد: تحضير / أوراق عمل / اختبارات / خطط
- نظام أحداث (Event Driven)
- فصل كامل بين UI والمنطق
- يعمل داخل GitHub Pages أو WebView

## الهيكل
- app.js → التشغيل وربط النظام
- ui.js → واجهة المستخدم
- generator.js → توليد المحتوى
- teacher-tools.js → أوامر المعلم
- curriculum-offline.json → المنهاج
- index.html → الواجهة
