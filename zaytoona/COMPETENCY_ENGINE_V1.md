# زيتونة Ω — محرك الكفايات العام v1

## الغاية
جعل الكفايات محورًا عامًا للتعلم والتقويم والإتقان، دون ربط المحرك بمادة أو موضوع واحد.

## المسار
الكفاية → المهارة → الهدف القابل للملاحظة → خبرة التعلم → الممارسة → التقويم → دليل الأداء → حكم الإتقان → تشخيص الفجوة → التدخل التالي → إعادة القياس.

## التشغيل
يُستخدم الكتالوج المحلي الناتج من مصدر كفايةت كطبقة معرفة قابلة للتتبع. لا تُرفع المادة إلى صفة مصدر رسمي لمجرد وجودها في المستودع.

## حدود v1
المحرك يوفّر الفهرسة والربط وحالة الإتقان الأساسية. التوليد التربوي المتخصص والتقويم المتقدم والتخصيص العميق مراحل لاحقة.

## قاعدة الاعتماد
لا تُعلن الجاهزية الكاملة قبل تحقق الكتالوج، التكامل، الاختبارات، والانحدار، ثم التحقق من النشر.
